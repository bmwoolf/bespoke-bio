# Variant panel source notes

Checked October 17, 2026 (Pacific). This is a computational research panel, not a battlefield treatment recommendation. Binder binding, allele selectivity, agonism/antagonism, secretion, and clinical benefit remain untested.

## Recommended initial panel

1. **GDF15 reference / H202D (rs1058587)**: strongest small variant benchmark. Use the literature's 112-aa 197–308 construct (H6D); UniProt currently annotates chain 195–308, which would make the same precursor variant H8D. Keep precursor and construct coordinates explicit. Native GDF15 is a disulfide-linked dimer. Primary assay work reports common H/D alleles and different recognition by some immunoassays, despite indistinguishable bioactivity in the tested receptor assay. Thus allele recognition is plausible without claiming an altered global fold or treatment benefit. [Primary assay study](https://academic.oup.com/jalm/article/7/6/1388/6633262), [UniProt Q99988](https://rest.uniprot.org/uniprotkb/Q99988.json).
2. **F7 reference / R413Q (rs6046)**: 406-aa mature zymogen (61–466), variant R353Q in mature numbering. This exact same allele appears as R391Q on current MANE transcript and R413Q on P08709. ClinVar reports 1000 Genomes minor-allele frequency 0.13838. Activation produces light61–212 and heavy213–466 chains linked by disulfide. Whole-protein folding omits Gla modification, calcium, glycans and tissue factor. For a cheaper domain-only experiment the 254-aa heavy chain contains variant R201Q, but that would not model complete clotting function. [ClinVar](https://www.ncbi.nlm.nih.gov/clinvar/variation/12080/), [UniProt P08709](https://rest.uniprot.org/uniprotkb/P08709.json), [Reactome](https://reactome.org/content/schema/instance/browser/uniprot%3AP08709).
3. **VEGFA165 reference**: 165-aa mature chain from P15692-4 precursor27–191. No common missense allele selected. Treat splice forms and regulatory SNPs as distinct from coding substitutions. The current canonical P15692 entry is 395 aa; older literature often calls a shorter precursor canonical, so fetch explicit isoform. Native receptor-binding surface is part of a disulfide-linked homodimer, with heparin/coreceptor and glycan context. [Exact isoform sequence](https://rest.uniprot.org/uniprotkb/P15692-4.fasta), [Protein Ontology isoform mapping](https://research.bioinformatics.udel.edu/pro/entry/PR%3AP15692/).
4. **APOE3 / APOE4 C130R (rs429358)**: optional expansion, 299-aa mature chain19–317; change becomes C112R. Canonical UniProt is E3. The 1000 Genomes minor C allele frequency is 0.15056; the ClinVar page represents the opposite/common allele in some frequency fields, so use its explicit GMAF rather than reading its ~0.85 as the E4 frequency. Strong lipidation and oligomer context makes apo single-chain fold differences uncertain. [UniProt P02649](https://rest.uniprot.org/uniprotkb/P02649.json), [ClinVar](https://www.ncbi.nlm.nih.gov/clinvar/variation/694742/), [NCBI isoform table](https://www.ncbi.nlm.nih.gov/books/NBK611310/table/lipid_dysbetal.T.major_isoforms_of_apo_e/?report=objectonly).

## Comparison design

For each coding pair, retain identical construct boundaries and model settings. In the executed campaign generation seeds were not controlled. Comparison Lightning/Torch seeds are 11/22/33, while native feature RNG remains independently initialized; report within-allele versus between-allele structural variation. Design against each allele, then predict every binder against both target alleles, using identical evaluation settings and replicate seeds. Same-target generation differences alone do not demonstrate selectivity. Report confidence and geometry as model outputs rather than affinity. Record whether the altered residue is contacted; an unguided design can land far from it. Dimer/assembly verification is essential for GDF15 and VEGFA before interpreting exposed surfaces.

Do not use regulatory-only associations (e.g. F2 G20210A or common promoter SNPs) as invented amino-acid variants. Hormone concentration is an input phenotype, not a protein sequence change. Steroid hormones are small molecules and outside the current protein-target flow.
